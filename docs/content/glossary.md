# Glossary

How readers say a thing, so the articles say it the same way. An article uses
the reader's word; the official Czech name follows in brackets at its first
use, for example «нострифицировать аттестат (nostrifikace)». The rules for
using this file are in [articles.md](../product/articles.md).

One row per term, with the word readers use in each language of the site. A
cell left empty is not known yet: a writer in that language reports the term
rather than guessing. «Explained in» gets the article that explains the term
when that article is merged. Anything marked «not yet checked» is checked
against its official source before an article states it.

| нострификация, нострифицировать аттестат | | | nostrifikace (the full official name not yet checked) | Recognition of a foreign school-leaving certificate as equal to a Czech one; readers say «нострифицировать», not «оценить аттестат». | |
