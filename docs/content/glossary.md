# Glossary

How readers say a thing, so the articles say it the same way. An article uses
the reader's word; the official Czech name follows in brackets at its first
use, for example «нострифицировать аттестат (nostrifikace)». The rules for
using this file are in [articles.md](../product/articles.md).

One row per term. «Explained in» links the article that explains the term,
once one is published; until then it is empty.

| Как говорят | Official term | What it is | Explained in |
| --- | --- | --- | --- |
| нострификация, нострифицировать аттестат | nostrifikace (uznání zahraničního středoškolského vzdělání) | Recognition of a foreign school-leaving certificate as equal to a Czech one; the reader says «нострифицировать», not «оценить аттестат». | |
| оценка аттестата факультетом | Each faculty names it on its own page; take the name from there (not yet checked) | A faculty checks the foreign certificate for its own admission only; it is not valid at other faculties. | |
